# Survival-Modelling-of-Mortality-Rates-with-Gompertz-GLMs
This project analyses mortality rates using survival models, focusing on Gompertz-based Generalized Linear Models with binomial errors. Observed death rates are modelled across ages 25–80, with model fit assessed using residual diagnostics and AIC comparisons between linear and quadratic Gompertz specifications.
